# 绿证市场政策事件本体（Event Ontology）v0.1

> 用途：L2 层 LLM 事件抽取的类型体系与属性定义。是人工标注、模型抽取、事件图谱构建三方共同遵守的"宪法"。
> 版本规则：本体变更必须升版本号并记录在文末变更日志，标注集与抽取结果都要标注所用本体版本。

## 1. 设计原则

1. **面向预测而非面向百科**：每个事件类型都必须能回答"它对绿证价格/供需意味着什么"，不做为分类而分类
2. **可标注性优先**：类型之间边界要能让标注员在 30 秒内做出判断；边界模糊的合并
3. **与价格机制对齐**：绿证价格由行政规则驱动（消纳权重、考核扩容、年份定价），本体的六个大类直接映射价格驱动因子
4. **可证伪**：每条抽取结果必须带 evidence_span（原文证据片段），无证据的事件视为幻觉丢弃

## 2. 事件大类与子类

### A. 政策发布（policy_release）
顶层制度供给。通常是中远期影响，改变市场预期结构。

| 子类 | 定义 | 例子 |
|---|---|---|
| A1 顶层规划 | 国家级的意见/方案/规划 | 《促进数字化绿色化协同转型发展实施方案(2026-2030)》 |
| A2 实施细则 | 对已发布政策的操作化文件 | 《可再生能源绿色电力证书管理实施细则（试行）》 |
| A3 管理办法 | 常态化管理制度 | 绿证核发、交易、核销管理办法 |
| A4 征求意见 | 征求意见稿发布（信号意义：政策方向预告） | 绿证交易实施细则征求意见稿 |

### B. 考核范围扩容（scope_expansion）
需求侧冲击的最直接来源。每扩容一个行业/主体 = 新增刚性绿证需求。

| 子类 | 定义 | 例子 |
|---|---|---|
| B1 新增考核行业 | 某行业首次纳入绿电消费考核 | 电解铝→钢铁/水泥/多晶硅 |
| B2 新增考核主体类型 | 非行业维度的新主体 | 国家枢纽节点新建数据中心 80% |
| B3 考核力度升级 | 从"监测不考核"变"硬考核" | 某省对钢铁行业开始考核 |

### C. 消纳责任权重调整（weight_adjustment）
分省约束值的变化，直接决定补证需求量。

| 子类 | 定义 | 例子 |
|---|---|---|
| C1 年度权重下达 | 国家下达各省年度权重 | 2025/2026 年消纳责任权重通知 |
| C2 权重上调/下调 | 预期值或约束值的调整 | 某省非水电权重 30%→32% |
| C3 省级分解方案 | 省级将权重分解到行业/企业 | 宁夏 2025 年消纳责任权重分解方案 |

### D. 价格信号（price_signal）
官方披露的量价信息，是 RQ1 的关键数据补充。

| 子类 | 定义 | 例子 |
|---|---|---|
| D1 官方价格通报 | 能源局/交易中心发布的均价数据 | "2026 年生产绿证均价 6.10 元/张" |
| D2 成交量通报 | 交易量、挂牌量披露 | "2024 年绿证交易 4.46 亿个" |
| D3 价格异常说明 | 官方对价格波动的原因解释 | 对绿证价格暴涨/暴跌的回应 |

### E. 供需冲击（supply_demand_shock）
非考核类的供需变化事件。

| 子类 | 定义 | 例子 |
|---|---|---|
| E1 核发放量 | 绿证核发规则放宽、核发范围扩大 | 分布式光伏纳入核发 |
| E2 需求放量 | 大用户/出口企业/CBAM 驱动的采购 | 某省组织绿证集中采购 |
| E3 供给受限 | 核发暂停、项目受限 | 某类项目暂停核发 |

### F. 市场规则变更（market_rule_change）
交易机制本身的变化，影响流动性和价格发现。

| 子类 | 定义 | 例子 |
|---|---|---|
| F1 交易规则 | 交易方式、平台、频次变化 | 绿证挂牌交易规则修订 |
| F2 绿电直连 | 直连政策（影响绿证替代路径） | 《关于有序推动多用户绿电直连发展的通知》 |
| F3 核销与有效期 | 核销规则、跨年使用规则 | 绿证按生产年份定价规则 |
| F4 国际互认 | 与 RE100/CBAM 等的互认进展 | 绿证国际互认谈判进展 |

## 3. 事件属性（五元组 + 扩展）

每条事件抽取为一个 JSON 对象：

| 字段 | 类型 | 取值 | 说明 |
|---|---|---|---|
| event_type | enum | A/B/C/D/E/F | 大类 |
| subtype | enum | A1-A4, B1-B3 等 | 子类 |
| actor | string | 发布主体（如"国家能源局"） | 规范化到机构名 |
| object | string | 受影响对象（如"数据中心""电解铝行业"） | 可为空 |
| strength | enum | 约束性 / 预期性 / 倡导性 | 约束力度，政策效力的关键区分 |
| effective_date | string | YYYY-MM-DD 或 YYYY-MM 或 "未明确" | 生效时间（≠发布时间） |
| region | string | 全国 / 省份名 | 地域范围 |
| industry | list | 涉及行业列表 | 可多值 |
| price_direction_prior | enum | 上行 / 下行 / 中性 / 不明 | 标注员/模型对价格方向的先验判断，供 RQ1 检验 |
| evidence_span | string | 原文中的证据片段（≤100 字） | **必填，无证据=幻觉** |

## 4. 边界规则（标注员高频疑问预案）

1. 一篇文档可抽取多条事件（如权重通知同时是 C1+C3），但同子类同对象只留一条
2. "征求意见稿"标 A4，转正后标 A1/A2/A3，两条都要（时间序列上方向相反的信号）
3. 新闻评论类（如"绿电消纳破新题"）：只抽其中引用的官方事实，不抽观点
4. 无法确定 strength 时看措辞："约束性指标/考核"→约束性；"预期/力争"→预期性；"鼓励/支持"→倡导性
5. 价格数字只标 D 类事件，模型预测用的价格序列来自 prices 表，不从文本重复采

- v0.2（2026-10-05，基于 pilot 仲裁记录修订）：

  3. 新闻评论类文章的 evidence 必须落到文中引用的官方原句，actor 标被引机构而非媒体（重申 v0.1 边界规则 3）
