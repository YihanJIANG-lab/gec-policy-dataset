# L2 级联抽取工程设计 v0.1

> 记录模型选型决策、测试证据与级联架构。模型选型必须可复现：本文档即选型依据。
> API 配置见 `config/api.local.yaml`（含密钥，不得外传/提交公开仓库）。

## 1. 级联架构

```
全量政策文档（documents 表，预计数万篇）
  └─ 第一层 初筛（triage: gemini-3.8-flash）
       判断"本文是否含政策事件"，过滤 60-70% 无关文档，成本≈0
       └─ 第二层 精抽（extract: qwen3.7-max）
            按 config/event_schema.json 输出事件五元组，写 events 表
            └─ 第三层 交叉验证（crosscheck: gpt-5.6-sol）
                 仅 B/C/D 类且 strength=约束性 的高价值事件
                 两模型结果不一致 → 人工复核队列
```

## 2. 选型测试记录（2026-09-13，中转站 [anonymized-api-relay]）

探测：GET /v1/models 返回 116 个可用模型 ID。
测试方法：对 2 篇事件富集文档（#42《2025年消纳责任权重通知》2335字、#48《绿证市场高质量发展意见》3752字）用统一 prompt + event_schema 调用，校验 JSON 合法性/枚举值/evidence_span，人工比对抽取内容。原始结果存 `data/annotation/extract_test_*.json`。

### 质量对比（doc #42，人工判断）

- **gpt-5.6-sol（6 事件）**：召回最全——把 2025 权重（约束性）与 2026 权重（预期性）拆成两条 C1（正确！），并捕获"核算以绿证为主"的 F3 规则（其他模型漏）
- **qwen3.7-max（4 事件）**：主干事件（C1/B1/F3/C3）全部命中、字段规范，漏 2026 预期性权重与核算规则
- **gemini-3.8-flash（4 事件）**：主干命中但 effective_date 全标"未明确"、1 条子类归错（F3→B3），只够初筛用

## 3. 最终选型

| 角色 | 模型 | 端点 | 理由 |
|---|---|---|---|
| 初筛 | deepseek-flash | **官方** api.deepseek.com | 召回导向（18 事件/doc48），过度抽取对初筛无害；官方定价下单篇约 ¥0.1-0.2 |
| 精抽 | deepseek-v4-pro | **官方** api.deepseek.com | 合并分寸最佳（10 事件/doc48，无冗余拆分），strength 判断准确，召回接近 gpt-5.6-sol |
| 精抽备选 | qwen3.7-max | 中转站 | 稳定性已验证，官方 key 故障时切换 |
| 交叉验证 | gpt-5.6-sol | 中转站 | 召回与细粒度判断最佳，只用于高价值子集 |

**原则：论文正式实验数据一律由官方 API 端点产出；中转站仅用于开发调试。**

### 二轮复测补充记录（2026-09-13 19:29）

- deepseek-v4-flash / v4-pro（无版本后缀）仍 500/429；**版本后缀型号 deepseek-v4-flash-0731 恢复可用**，deepseek-v4-pro-0813 仍 504
- deepseek-v4-flash-0731 已知问题：effective_date 会虚构日级精度（"2025-01-01"，原文仅到年份）；输出冗长（5568 token）。生产 prompt 需加"日期精度不得超过原文明确程度"规则
- deepseek-v3.2 抽取"B1 增设行业"标 strength=约束性（对电解铝考核而言比其他模型的"预期性"更准确）

### 三轮测试：官方 DeepSeek API（2026-09-13 19:50）

- 官方端点探测可用模型：deepseek-flash、deepseek-v4-pro（`config/api.deepseek.yaml`）
- doc #48 表现：flash 18 事件（过度抽取，6 条 F1 未合并，违反"同子类同对象只留一条"）；v4-pro 10 事件（合并恰当，质量参评最优）
- 官方模型带推理链，输出 1-1.5 万 token/篇，但官方定价下单篇成本约 ¥0.1-0.2，可接受
- v4-pro 单篇延迟 120-140s，生产管道必须并发调用
- 定性意见类文档（无明确日期）各模型标"未明确"为正确行为；日期虚构只出现在中转站 v4-flash-0731

## 4. 学术与工程风险记录

1. **可复现性风险**：中转站模型可能被静默重新指向或下线（已观测到 deepseek 全系不可用）。论文必须记录：调用日期、模型 ID、中转站来源；正式实验前用官方 API（DeepSeek/阿里百炼/OpenAI）复跑 gold set 评测作为最终数据
2. **数据合规**：政策文档均为公开文本，经中转站发送无敏感信息问题；但若未来处理企业数据，必须切官方 API 或本地模型
3. **成本**：中转站按量计费明细未知，批量生产前先用 100 篇试跑估算单篇成本
4. gold set 冻结后，三个模型在 gold set 上的 F1 对比表进论文实验节（本测试仅 2 篇，仅为工程选型，不能作为论文数据）
