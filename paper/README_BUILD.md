# LaTeX build

Use pdfLaTeX with acmart 2.16 (2025-08-27); the unmodified class is included under its original LPPL notice. Other required packages are supplied by MiKTeX or TeX Live. Run pdflatex -interaction=nonstopmode -halt-on-error -recorder main.tex three times. TEX_ENVIRONMENT.json records the successful local environment and source dependencies.

The current draft is for internal author review. Candidate author order, affiliations, reviewer resource URL and archival DOI still require completion before submission.
